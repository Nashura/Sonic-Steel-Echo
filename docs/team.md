# Команда проекта «Sonic: Steel Echo»

Мы разрабатываем игру с пошаговой боевой системой на ActionScript 3.0 
в Adobe Animate. В команде три участника.

## Состав команды и распределение ролей

**Шарипов Аскар Бобомуродович  — разработка и анимация.** Реализует на ActionScript 3.0 выбор действий, смену ходов, расчёт урона и обновление показателей здоровья. Собирает сцену боя в Adobe Animate и создаёт на временной шкале катсцены и анимации обычной атаки, специальные атаки, лечение и получения урона. Связывает анимации с кодом и готовит сборки для тестирования и демонстрации. GitHub — `@Nashura`.

**Янкунас Глеб Георгиевич — геймдизайн, баланс и тестирование.** Описывает правила боя и поведение врага, подбирает параметры здоровья, урона, защиты и единицы лечения. Проверяет победу, поражение, повторный запуск боя и обработку нажатий во время анимаций. GitHub — `@rawyzome`.

**Жерновская Варвара Владимировна — сценарий, графика и материалы для защиты.** Пишет сценарий встречи героя с противником, продумывает финал демонстрации проекта и готовит раскадровку катсцен. Подготавливает спрайты персонажей, фон, иконки действий и элементы отображения здоровья. Собирает иллюстрации для презентации проекта. Затем добавляет в игру музыкальное сопровождение. GitHub — `@Varvara44`.

## Общение и созвоны

- Telegram используем для быстрых вопросов, обсуждений и согласования времени встреч.
- Предлагаемый график — один созвон в неделю, в воскресенье в 19:00 по Кемерову.
  На созвоне каждый кратко сообщает, что готово, что мешает работе и что он
  планирует сделать дальше. Время подтверждаем в чате.
- Если задача блокирует работу другого участника или есть риск пропустить срок,
  сообщаем об этом в чате и обновляем задачу на доске.

## Как работаем с репозиторием

1. Для каждой задачи создаём Issue с исполнителем, сроком и условием готовности.
2. Каждый участник добавляет свои материалы в отдельной ветке и открывает Pull Request.
3. Другой участник проверяет результат по описанию задачи. После проверки
   изменения объединяем с веткой `main`, а задачу переводим в `Done`.
4. Основной `.fla` редактирует разработчик, чтобы избежать конфликтов при
   слиянии. Глеб и Варя добавляют свои материалы через отдельные ветки.
   Код ActionScript 3.0 храним во внешних `.as`-файлах в папке `src/`.

Статусы на доске: `Backlog` → `Ready` → `In progress` → `In revies` → `Done`.
